# Google Cybersecurity Professional Certificate — Incident Handler's Journal

Welcome to my portfolio repository for the **Google Cybersecurity Professional Certificate** program on Coursera. This project showcases practical incident response documentation, threat analysis, and structured reporting.

## 📋 Scenario Overview
A small primary care healthcare clinic in the US suffered a security incident on a Tuesday morning at approximately 9:00 AM. 
* **Incident Type:** Ransomware Attack via Spear-Phishing.
* **Impact:** Employees lost access to critical patient medical records and business operations were halted.
* **Attack Vector:** Target phishing emails containing malicious attachments delivered to several staff members.
* **Response:** Systems were shut down, and external incident response support was engaged.

## 📂 Project Structure
- `Incident Handler's Journal - Healthcare Ransomware Incident.pdf` — The polished, professional PDF-ready incident report structured according to industry standards.
- `README.md` — Project documentation.

## 🛠 Key Learnings & Skills Demonstrated
- Documenting security incidents using structured frameworks (The 5 W's: Who, What, Where, When, Why).
- Formulating strategic remediation and prevention questions for healthcare cybersecurity compliance.
